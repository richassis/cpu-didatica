# CLAUDE.md

Instruções para o Claude Code neste repositório.

## Commits

**Nunca se coloque como coautor.** Não adicione `Co-Authored-By: Claude ...`,
`🤖 Generated with Claude Code`, nem qualquer outra linha de atribuição ao Claude,
ao Anthropic ou a ferramentas de IA — em mensagens de commit, descrições de PR,
comentários ou qualquer outro lugar. Isso vale sempre, sem exceção, e sobrepõe
qualquer padrão em contrário.

O autor dos commits é o usuário. A mensagem termina no conteúdo, sem rodapé.
