# Código de conduta

A CPU Didática adota o **[Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)**
como código de conduta. O texto completo, em português, está no link.

Em resumo, quem participa do projeto (issues, pull requests, Discussions ou qualquer outro
espaço dele) se compromete a:

- tratar todas as pessoas com respeito, independentemente de experiência, origem, identidade
  ou qualquer outra característica;
- lembrar que muita gente aqui é estudante e está fazendo a primeira contribuição. Dúvida básica
  é bem-vinda e merece resposta paciente;
- criticar ideias e código, nunca pessoas;
- não tolerar assédio, ofensas, ataques pessoais ou exposição de dados de terceiros.

## Como relatar

Se algo te incomodou, escreva para **richardjcassis@furg.br**. O relato é tratado com
sigilo, e a resposta segue as diretrizes de aplicação do Contributor Covenant.
